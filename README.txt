QUERUX v6 - ESTILO OSCURO

Incluye:
- Logo Querux como icono de la app
- Fondo oscuro estilo financiero
- Verde neón como color principal
- Rojo para gastos/alertas
- Tarjetas oscuras con bordes suaves
- Gráfico pastel/dona por categoría
- Presupuesto mensual
- Ingresos, gastos, saldo y movimientos
- Conserva los datos anteriores mediante la misma clave localStorage

Actualización en GitHub:
1. Descomprime el ZIP.
2. En mis-gastos > Add file > Upload files.
3. Sube los archivos a la raíz del repositorio.
4. Reemplaza los anteriores y pulsa Commit changes.
5. No borres los datos del navegador si quieres conservar tus registros.
